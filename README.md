# Ataya

<p align="left">
  <img src="Ataya/ataya-logo.png" alt="Ataya Logo" width="140">
</p>

Ataya is an iOS mobile application developed using Xcode that aims to reduce food waste by facilitating a secure and organized food donation process.

The application connects food donors with verified NGOs and volunteer collectors, allowing donations to be submitted, reviewed, scheduled, collected, and tracked through a structured workflow.

Ataya promotes transparency, food safety, and community engagement by providing clear donation status updates and administrative oversight.

## Main Features

| Feature                              | Explanation                                                                                                             | Developer      |

| Organization Discovery               | Enables users to browse verified NGOs, their missions, and available donation options                                   | Sarah Abdulla  |
| Pickup Scheduling                    | Enables NGOs to accept or reject requests, schedule pickup date/time and location, and prevent conflicts                | Rana Alqameesh |
| Real-Time Donation Status Tracking   | Displays donation status updates such as pending, accepted, scheduled, collected, and completed                         | Ruqaya Khan    |
| Donation History & Activity Logs     | Stores donation history and logs user actions for tracking and auditing                                                 | Ruqaya Khan    |
| Recurring Donation Schedules         | Allows users to set recurring donation plans for repeated contributions over time                                       | Ameena Khamis  |
| Impact Tracking Dashboard            | Shows impact statistics and insights through dashboard analytics                                                        | Ameena Khamis  |
| Notifications                        | Sends automatic alerts for donation updates, pickup confirmations, approvals, and important system events               | Rana Alqameesh |
| Admin Panel                          | Provides admin tools to manage users, monitor activity, and oversee the donation workflow                               | Maram Shubbar  |
| Admin Flow                           | Supports admin processes such as verification of collectors/NGOs and handling flagged content or suspicious activity    | Sarah Abdulla  |
| Gamification: Achievements & Rewards | Encourages engagement using points, badges, achievements, and reward milestones                                         | Maram Shubbar  |

## Technologies & Libraries

* **Swift** — Primary programming language used to develop the iOS application
* **UIKit** — Used to build the application's user interface and interactive components
* **Xcode** — Integrated development environment used to develop, build, run, and test the application
* **Firebase Authentication** — Provides secure user authentication and identity management
* **Firebase Firestore** — Stores users, donations, campaigns, reviews, and other application data with real-time synchronization
* **Firebase App Check** — Helps protect Firebase resources by allowing requests only from authentic app instances
* **DGCharts** — Provides charts and visual analytics for dashboards and reports
